# ALZHEIMER-Web-Application-
This project is a simple and user-friendly web application designed to support individuals affected by Alzheimer’s disease. The application is built using JSP, HTML, CSS, and JavaScript and focuses on providing light cognitive activities and essential health awareness to help delay the progression of symptoms.
